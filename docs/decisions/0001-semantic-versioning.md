# 0001 — Semantic versioning per roadmap phase

**Status:** accepted

The project is versioned `MAJOR.MINOR.PATCH`. During pre-1.0 development each
completed roadmap phase is a minor release, fixes are patch releases. Each release
updates `package.json`, adds a `CHANGELOG.md` section and is tagged `vX.Y.Z`.
`1.0.0` is reserved for the MVP defined in `PROJECT_VISION.md` §18.
